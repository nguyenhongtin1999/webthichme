================================================================================
                          FEATURE FLOW
================================================================================

1. User Long-Presses Plus Button (500ms)
   └─> onMouseDown / onTouchStart triggers
   └─> setTimeout(500ms) starts
   └─> If still pressed after 500ms...

2. Voice Modal Opens with Animation
   └─> Backdrop fades in with blur
   └─> Modal slides in from bottom
   └─> Waveform ready for animation

3. User Clicks "Bắt đầu" (Start)
   └─> Web Speech API starts listening
   └─> Mic button turns red
   └─> Waveform animation begins

4. User Speaks
   └─> Audio is captured by microphone
   └─> Real-time transcription processes
   └─> Text appears in transcript box
   └─> Waveform visualizes sound levels

5. User Clicks "Dừng" (Stop)
   └─> Speech recognition stops
   └─> Transcript is finalized
   └─> onTranscript callback is triggered
   └─> Modal can close

6. Custom Handler Called
   └─> handleVoiceTranscript(text) executes
   └─> Your custom logic runs
   └─> Can search, navigate, or process

================================================================================
                        TROUBLESHOOTING
================================================================================

PROBLEM: Modal doesn't appear
  SOLUTION:
    - Check if holding for full 500ms
    - Verify event listeners attached
    - Check browser console for errors
    - Try refreshing page
    - Test with developer tools

PROBLEM: Microphone won't work
  SOLUTION:
    - Grant microphone permission
    - Check device microphone settings
    - Verify HTTPS connection
    - Try different browser
    - Restart device

PROBLEM: Waveform animation is choppy
  SOLUTION:
    - Close other browser tabs
    - Check device CPU usage
    - Update browser to latest
    - Try different browser
    - Disable browser extensions

PROBLEM: Text not transcribing
  SOLUTION:
    - Speak louder and clearer
    - Reduce background noise
    - Check language matches speech
    - Verify internet connection
    - Check microphone volume
